# Planning shelf

This is the proofing drawer of the [softbake.dev](https://softbakedev.github.io) recipe blog. Articles that are not yet ready to ship live here as short coming soon notes, so readers can see what is in the oven and contributors know which slugs are already taken.

Each note in this folder describes what the upcoming recipe will cover and roughly when to expect it. When an article is ready to bake for real, it moves up one level into its own folder under [`recipes/`](../) with a full `README.md`, and the note in this folder is removed.

## What is proofing right now

Two recipes are next on the tray.

*Planning a sprint kitchen for baker agents* picks up where the first recipe leaves off and goes deep on what right planning looks like when agents do the heavy build work. The full note is in [`planning-a-sprint-kitchen-for-baker-agents.md`](./planning-a-sprint-kitchen-for-baker-agents.md).

*Body shopping versus agent shopping* compares the two delivery models head to head, the traditional one that rents developer bodies by the hour and the Softbake one that rents agent capacity orchestrated by a human master chief. The full note is in [`body-shopping-versus-agent-shopping.md`](./body-shopping-versus-agent-shopping.md).

## Adding a new note

If you are seeding a new recipe, create a markdown file in this folder named after the article slug in kebab case, drop in the frontmatter and a few honest paragraphs about what the piece will cover, and open a pull request. Keep it short. The note is a promise, not a draft.
